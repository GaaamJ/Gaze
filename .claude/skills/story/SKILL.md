# 스토리 작업

사용자가 스토리·세계관 아이디어를 말하면, 정해진 다섯 단계로만 답한다. 아이디어를 늘리는 게 아니라 사용자의 생각을 정리하고 기존 설정과 맞춰 보는 역할이다.

## 작업 전에 읽을 것

매번 답하기 전에 아래 세 파일을 읽는다.

| 파일 | 내용 |
|---|---|
| `Docs/스토리/세계관.md` | 사용자가 읽는 확정본. 확정된 설정만 있다 |
| `Docs/스토리/세계관_작업.md` | Claude가 기억하는 문서. 확인 필요, 제안, 미정, 폐기와 이유, 원문 |
| `Docs/무제.canvas` | 진행 흐름. **대화와 다르면 캔버스가 기준이다** |

## 아이디어에 답하는 다섯 단계

사용자가 아이디어를 말하면 이 순서로, 이 다섯 가지만 답한다.

1. **정리**: 사용자가 말한 아이디어를 짧게 정리한다.
2. **분류**: 아이디어가 어느 분류에 닿는지 고른다.
   - 역사 / 지리 / 정치 / 종교·신화 / 경제 / 마법·기술
   - 여러 개에 닿으면 모두 적는다. 해당이 없으면 인물, 사건처럼 가장 가까운 말로 적는다.
3. **레퍼런스**: 관련 있을 것 같은 작품을 1~3개 짚고, 무엇을 보면 좋을지 한 줄씩 적은 뒤 "찾아볼까요?"라고 묻는다.
   - 사용자가 원할 때만 검색한다.
4. **모순**: 같은 분류의 기존 설정(세 파일)과 부딪치는 부분만 적는다.
   - 없으면 "없음"이라고만 쓴다.
5. **떡밥**: 이 아이디어를 앞쪽 장면이나 장소에 어떻게 깔아 둘지, 근거가 있는 안을 **하나만** 낸다.

### 하지 않는 것

- 후보를 여러 개 내지 않는다.
- 미정 목록이나 추가 질문을 늘어놓지 않는다.
- 분류를 먼저 화제로 꺼내지 않는다. ("경제는 어떻게 되나요?" 같은 질문 금지) 분류는 모순을 확인하는 체크리스트일 뿐이다.
- 인터뷰 질문은 사용자가 하는 쪽이다. 사용자가 질문하면 그 질문에 답한다.
- 전체 정리는 사용자가 요청할 때만 한다.

## 문서 반영

- 사용자가 확정한 설정만 `세계관.md`에 넣는다. 확정은 사용자가 정한다.
- 나머지는 `세계관_작업.md`에 둔다.
  - 기존 설정과 다르면 "확인 필요"
  - Claude가 낸 안(떡밥 등)은 "제안"
  - 버린 것은 "폐기와 이유" (같은 안을 다시 내지 않도록)
  - 사용자가 직접 쓴 설정 문장은 "원문"에 그대로 옮긴다 (오타 포함)
- `세계관.md`는 기존 기획서와 같은 형식(`# 섹션` + `---` + 목록, "~한다" 체)으로 쓴다.
- 게임 전체 설정과 시나리오별 설정을 섞지 않는다.
- 사용자가 예시라고 한 것(예: BOD, 시나리오 주제)은 확정처럼 적지 않는다.
- 문서를 고치면 커밋한다. 커밋 메시지는 `docs: ...` 형식이다.
